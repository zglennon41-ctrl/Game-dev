# docs/

One file per system, in buildable detail. `HANDOFF.md` at the repo root decides; these
explain.

The full design lives in three Claude Docs. Export each as Markdown and drop the files
here so Claude Code can read them offline:

| Export as | From |
| --- | --- |
| `bible.md` | Design Bible — https://claude.ai/artifact/8XisZssaRVrz4gRMYfqe2n |
| `systems-*.md` (one per tab) | Systems — https://claude.ai/artifact/2g1k1EJT7Mbnr3ujqPZVH9 |
| `guide-*.md` (one per tab) | The Guide — https://claude.ai/artifact/LD6bW3LhYrpS2jcbd4eM4k |

`three-lives.md` is already here: it is the acceptance test for the simulator.

When a doc and `HANDOFF.md` disagree, `HANDOFF.md` wins. When two docs disagree, the
Systems doc wins over the Bible, and the Guide wins over both for the field, the genius,
and skills-to-jobs.
